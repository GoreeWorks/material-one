# Material One Component System

Material One components are:

- adaptive
- state-aware
- accessible
- reusable

## Component States

Every component supports:

- Default
- Focused
- Pressed
- Selected
- Disabled
- Loading
- Success
- Warning
- Error

## Intelligent Components

Components may adapt:

- size
- density
- arrangement
- available actions
- interaction style

based on device, preferences, and context.
