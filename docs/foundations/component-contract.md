# Material One Component Contract

A Material One component is defined by behavior, semantics, and adaptation rules rather than visual styling alone.

## Component Definition

Each component should document:

## Anatomy

The structural regions that make up the component.

## Semantic Dependencies

Components consume semantic roles:

- surface
- content
- emphasis
- interaction
- status
- focus
- disabled

## State Model

Required states include:

- default
- hover
- focus
- pressed
- selected
- disabled
- loading
- error
- success where applicable

## Adaptive Behavior

Components define changes for:

- compact layouts
- touch interaction
- keyboard interaction
- reduced motion
- increased text scale
- high contrast environments

## Accessibility

Every component must define:

- keyboard behavior
- assistive technology semantics
- focus treatment
- non-color communication methods

## Motion

Motion communicates state transitions and follows the Material One semantic motion framework.
