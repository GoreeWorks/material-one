# Material One Adaptive Layout System

## Purpose

Material One layouts adapt to device, workflow, and human interaction needs while maintaining a consistent design language.

## Layout Modes

### Compact

Optimized for phones and focused tasks.

Principles:
- Reachable controls
- Reduced complexity
- Priority-driven content
- Fast interaction

### Expanded

Optimized for tablets and larger displays.

Principles:
- Additional information visibility
- Multi-content workflows
- Flexible navigation

### Workspace

Optimized for professional environments.

Principles:
- Persistent navigation
- Multiple panels
- Customizable workspace
- Advanced workflows

## Adaptation Inputs

Layouts respond to:

- viewport size
- orientation
- input method
- accessibility settings
- user preferences
- task context

## Design Rule

Adaptation should improve usability without creating inconsistent experiences.
