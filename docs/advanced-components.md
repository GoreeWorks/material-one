# Material One Advanced Components

## Purpose

Advanced components extend the Material One component foundation into complete interaction patterns.

## Overlay Components

Material One overlays include:

- Dialogs
- Sheets
- Menus
- Popovers
- Tooltips

Overlays must preserve:

- semantic colors
- typography roles
- motion intent
- keyboard navigation
- focus management

## Navigation Patterns

Navigation adapts by layout:

- Compact: navigation bar
- Expanded: navigation rail
- Workspace: persistent sidebar

## Data Surfaces

Data-heavy interfaces use adaptive presentation:

- compact screens stack content
- medium layouts use grids
- workspace layouts support tables and parallel workflows

Loading uses Material One skeleton and progressive loading contracts.

## Application Patterns

Future Material One applications should compose:

Application Shell
→ Navigation
→ Content Surfaces
→ Data Patterns
→ Personalization Layer
→ Accessibility Layer

Components are not isolated visuals. They are adaptive interface behaviors.
